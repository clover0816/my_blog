离散对数问题: 对于 $g^x \equiv c \pmod{n}$ , $g$ 是 $n$ 的原根, $c$ 不等于 $0$, 给定 $g, c, n$, 我们很难求出指数 $x$.

不过, 在某些特定的情况下, 也有一些算法可以求出指数.

## 攻击

### Brute Force 暴力搜索

#### 原理

这是最直接的方法, 即从 $0$ 开始枚举指数 $x$ , 最终找到满足 $g^x \equiv c \pmod{n}$ 的指数 $x$ .

适用于模数较小的情况, 时间复杂度为 $O(q)$ , $q$ 为 $g$ 的阶.

#### 代码

```py
x = 0
while True:
    if (pow(g, x, n) == c):
        print(x)
        break
    x += 1
```

### Baby-step Giant-step

#### 原理

他的核心思想是将一个很大的指数拆成两个小指数, 通过查表匹配来得到 $x$ .

我们要求 $g^x \equiv c \pmod{n}$ , 令 $m = \left\lceil\sqrt{q}\right\rceil$ , $q$ 为 $g$ 的阶 , 这样 $x = am + b$ , 其中 $0 \le a, b < m$ .
$$
\begin{align}
g^x = g^{am + b} \equiv c &\pmod{n}\\
g^{b} \equiv c \cdot \left(g^{-m}\right)^{a} &\pmod{n}\\
\end{align}
$$

随后我们可以枚举 $a, b$ , 直到找到可以满足 $g^{b} \equiv c \cdot \left(g^{-m}\right)^{a} \pmod{n}$ 的 $a, b$ , 然后得到 $x$ , 时间复杂度为 $O(\sqrt{q})$ .

#### 代码

```py
from Crypto.Util.number import *
import gmpy2
import math

def bsgs(g, c, n):
    q = Mod(g, n).multiplicative_order()
    m = int(math.ceil(gmpy2.isqrt(q)))

    table = {}
    cur = 1

    for b in range(m):
        table[cur] = b
        cur = cur * g % n

    factor = pow(pow(g, m, n), -1, n)
    cur = c % n

    for a in range(m):
        if cur in table:
            return (a * m + table[cur]) % q
        cur = cur * factor % n

    return None
```

### Pollard's Rho

#### 原理

核心原理: 通过随机游走寻找两个相同的数(碰撞), 利用碰撞建立一个关于指数 $x$ 的方程从而求出 $x$ .

我们要求解 $g^{x} \equiv c \pmod{n}$ , 可以构造 $z \equiv g^ac^b \pmod{n}$ .
$$
\begin{align}
z \equiv g^ac^b &\pmod{n}\\
c \equiv g^x &\pmod{n}\\
z \equiv g^{bx + a} &\pmod{n}\\
\end{align}
$$
当我们找到两个状态满足 $g^{a_1}c^{b_1} \equiv g^{a_2}c^{b_2} \pmod{n}$ , 则可构造 $b_1x + a_1 \equiv b_2x + a_2 \pmod{q}$ , $x \equiv (a_2 - a_1) \cdot (b_1 - b_2)^{-1} \pmod{q}$ .

期望时间复杂度为 $O(\sqrt{q})$ , 其中 $q$ 是 $g$ 的阶, 主要来自于生日悖论.

##### 随机游走

我们将一个状态定义为：$S_i=(z_i,a_i,b_i)$ , 其中始终满足: $z_i\equiv g^{a_i}c^{b_i}\pmod n$ .

初始状态可以取: $S_0=(1,0,0)$ , 接下来, 我们通过确定性的转移规则, 不断生成新的状态. 例如：

- 若 $(z_i\bmod3=0)$, 则令 $(z_{i+1},a_{i+1},b_{i+1})=(z_i^2,2a_i,2b_i)$ .
- 若 $(z_i\bmod3=1)$, 则令 $(z_{i+1},a_{i+1},b_{i+1})
  =(z_ig,a_i+1,b_i)$ .
- 若 $(z_i\bmod3=2)$, 则令 $(z_{i+1},a_{i+1},b_{i+1})=(z_ic,a_i,b_i+1)$ .

其中 $z$ 的运算模 $n$ , 指数 $(a,b)$ 的运算模 $q$ , $q$ 为 $g$ 的阶.

上述转移规则始终保证: $z_i\equiv g^{a_i}c^{b_i}\pmod n$ .

由于 $z_i$ 所在的集合是有限的, 而转移规则是确定的, 因此不断迭代后必然会出现重复的 $z$ , 并进入循环.

当找到两个不同位置 $(i,j)$ , 满足: $z_i=z_j\pmod n$ , 就可以利用对应的两组指数 $(a_i,b_i)$ 和 $(a_j,b_j)$ , 建立关于未知数 $x$ 的同余方程, 从而求解离散对数.

找寻阶段可以利用快慢指针, 快指针一次走两步, 慢指针一次走一步, 只要进入循环, 则最后快慢指针一定会相遇的.

#### 代码

```py
import random

def pollard_rho(g, c, n, q):
    # 状态 (z, a, b)，满足 z = g^a * c^b (mod n)

    def f(s):
        z, a, b = s

        if z % 3 == 0:
            return (z*z % n, 2*a % q, 2*b % q)
        elif z % 3 == 1:
            return (z*g % n, (a+1) % q, b)
        else:
            return (z*c % n, a, (b+1) % q)

    while True:
        a = random.randrange(q)
        b = random.randrange(q)
        z = pow(g, a, n) * pow(c, b, n) % n
        start = (z, a, b)

        slow = f(start)
        fast = f(f(start))

        while slow[0] != fast[0]:
            slow = f(slow)
            fast = f(f(fast))

        _, a1, b1 = slow
        _, a2, b2 = fast

        d = (b1 - b2) % q
        rhs = (a2 - a1) % q

        if d == 0:
            continue

        x = rhs * pow(d, -1, q) % q

        if pow(g, x, n) == c:
            return x

```

### Pohlig-Hellman

#### 原理

核心思想: 如果群的阶 $q$ 可以分解成多个较小的素数幂，那么我们可以把原来的离散对数问题拆成多个更小的问题.

假设 $q = l_1^{e_1} l_2^{e_2} l_3^{e_3} \cdots l_k^{e_k}$ , 其中 $l_i$ 是不同的素数. 那么我们就可以把 $x \bmod{q}$ 拆成
$$
\begin{align}
\left\{
\begin{matrix}
x \equiv x_1 \pmod{l_1^{e_1}}\\
x \equiv x_2 \pmod{l_2^{e_2}}\\
\cdots\\
x \equiv x_k \pmod{l_k^{e_k}}\\
\end{matrix}
\right.
\end{align}
$$
然后利用中国剩余定理进行合并, 得到 $x \bmod{q}$ .

#### 代码

```py
def pohlig_hellman(g, c, n):
    # 转换为模 n 的元素
    G = Mod(g, n)
    C = Mod(c, n)

    # 检查条件
    if gcd(g, n) != 1:
        raise ValueError("g 和 n 不互素")

    if gcd(c, n) != 1:
        raise ValueError("c 和 n 不互素")

    # 自动计算 g 的阶
    q = G.multiplicative_order()

    # 自动分解群阶
    print("g 的阶：", q)
    print("群阶分解：", factor(q))

    # 自动求离散对数
    try:
        x = discrete_log(C, G, ord=q)
    except ValueError:
        print("不存在离散对数")
        return None

    # 验证结果
    if G**x != C:
        return None

    print("求解成功，x =", x)
    return ZZ(x)
```

### Index Calculus

#### 原理

核心思想: 不直接寻找 $x$, 而是先求出一些比较小的数的离散对数, 再利用这些结果求出 $x$.

我们选取一些小素数, 构成一个集合, 例如 $\{2, 3, 5, 7\}$ , 这个集合叫做因子基, 接下来我们随便选择一个 $k$ , 计算 $g^k \pmod{n}$ , 如果结果可以被分解成因子基中素数的乘积, 则我们称这个数为平滑数.

我们收集一些平滑关系, 可以求出各个元素的离散对数, 举个🌰:

\[ 3^x\equiv13\pmod{17} \]

我们知道：$\operatorname{ord}_{17}(3)=16$ , 所以 $x\pmod{16}$ .

我们选择因子基 $S=\{2,3,5\}$.

现在开始寻找平滑关系.

假设我们计算得到:  $3^4\bmod17=13$ , $13$ 不能用因子基分解, 暂时没有用.

继续计算：
$$
\begin{align}
&3^3\bmod17=10\\
&3^5\bmod17=5\\
&3^6\bmod17=15\\
\end{align}
$$
而 $15=3\cdot5$ , 这就得到了一条平滑关系 $3^6\equiv3\cdot5\pmod{17}$ , 两边取以 $3$ 为底的离散对数: $6\equiv\log_3 3+\log_3 5\pmod{16}$

令: $L_2=\log_3 2, L_3=\log_3 3, L_5=\log_3 5$ , 那么: $L_3=1, L_3+L_5\equiv6\pmod{16}$ , 因此: $L_5=5$ .

我们已经得到了一些因子基元素的离散对数.

再继续收集关系, 例如 $3^4\bmod17=13$ , 虽然 $13$ 不平滑, 但 $13\cdot3^2=117\equiv15\pmod{17}$ ,  而 $15=3\cdot5$ , 所以 $13\cdot3^2\equiv3\cdot5\pmod{17}$.

两边取离散对数:  $\log_3 13+2\equiv L_3+L_5\pmod{16}$

代入: $\log_3 13+2\equiv1+5\pmod{16}$ , 于是 ${\log_3 13\equiv4\pmod{16}}$.

这就求出了目标离散对数。

#### 代码

```py
import gmpy2
from Crypto.Util.number import *

def factorize(v, base):
    """将 v 分解为因子基中的素数"""
    factors = {}

    for p in base:
        while v % p == 0:
            factors[p] = factors.get(p, 0) + 1
            v //= p

    if v == 1:
        return factors

    return None


def index_calculus(g, c, n, base, verbose=True):
    g, c, n = map(ZZ, (g, c, n))
    base = list(map(ZZ, base))

    # 1. 基本检查
    if not is_prime(n):
        raise ValueError("这个教学版本要求 n 为素数")

    if gcd(g, n) != 1 or gcd(c, n) != 1:
        raise ValueError("要求 g 和 c 都与 n 互素")

    G = Mod(g, n)
    C = Mod(c, n)

    # 2. 自动计算 g 的阶
    q = G.multiplicative_order()

    if C**q != 1:
        print("无解：c 不属于 g 生成的子群")
        return None

    if verbose:
        print("群阶 q =", q)
        print("因子基 =", base)

    # 3. 检查因子基元素是否属于 <g>
    for p in base:
        if not is_prime(p) or p == n:
            raise ValueError(f"{p} 不是合适的因子基素数")

        if pow(p, q, n) != 1:
            raise ValueError(
                f"因子基元素 {p} 不属于 g 生成的子群"
            )

    # 4. 收集平滑关系
    relations = []

    for k in range(q):
        v = pow(g, k, n)
        factors = factorize(v, base)

        if factors is not None:
            relations.append((k, factors))

    if verbose:
        print("\n收集到的平滑关系：")
        for k, factors in relations:
            print(f"g^{k} =", factors)

    # 5. 建立模 q 线性方程组
    A = []
    B = []

    for k, factors in relations:
        A.append([factors.get(p, 0) for p in base])
        B.append(k)

    if not A:
        print("没有收集到平滑关系")
        return None

    R = Zmod(q)
    M = matrix(R, A)
    V = vector(R, B)

    try:
        logs = M.solve_right(V)
    except (ValueError, ArithmeticError):
        print("线性方程组无法直接求解")
        print("可能需要更多关系，或需要处理模 q 下的多解")
        return None

    # 6. 验证因子基离散对数
    log_table = dict(zip(base, logs))

    for p, value in log_table.items():
        if pow(g, ZZ(value), n) != p % n:
            print("得到的因子基对数不正确")
            return None

    if verbose:
        print("\n因子基离散对数：")
        for p, value in log_table.items():
            print(f"log_g({p}) =", value)

    # 7. 寻找目标值的平滑关系
    for t in range(q):
        v = (c * pow(g, t, n)) % n
        factors = factorize(v, base)

        if factors is None:
            continue

        x = sum(
            ZZ(e) * ZZ(log_table[p])
            for p, e in factors.items()
        ) - t

        x = ZZ(x) % q

        # 8. 验证最终结果
        if pow(g, x, n) == c % n:
            if verbose:
                print("\n目标值的平滑关系：", factors)
                print("求解成功，x =", x)

            return x

    print("没有找到目标值的平滑关系")
    return None
```

NFS 可以看成 Index Calculus 思想的一种高级实现, 它通过数域中的代数结构, 更高效地寻找平滑关系.

## Diffie-Hellman 密钥交换协议

### 原始 Diffie-Hellman 密钥交换协议

#### 原理

Diffie-Hellman 密钥交换协议的安全性就建立在求解离散对数问题的困难性上.

现在我们假设有 Alice 和 Bob 两个人, 两个人想要进行交流, 但不想要第三人知道, 他们采取了 Diffie-Hellman 密钥交换协议来进行交流, 我们来通过这个场景解释这个密钥交换协议的具体实施.

首先, 两人要事先约定好一个大素数 $P$ 以及该素数的原根 $g$ .

Alice 选择一个私钥 $a$ , 并利用这个私钥生成公钥 $A = g^a \pmod{P}$ , 将这个公钥发给 Bob.

Bob 接收到 Alice 的公钥, 随后选择一个私钥 $b$ , 并生成公钥 $B = g^b \pmod{P}$ , 随后将公钥 $B$ 发送给 Alice.

Alice 接收到 Bob 的公钥后, 可以进行计算 $S_a = B^{a} \pmod{P}$ , 而 Bob 也可以进行计算 $S_b = A^{b} \pmod{P}$ .

而我们知道 $S_a \equiv B^a \equiv (g^b)^a \equiv (g^a)^b \equiv A^b \equiv S_b \pmod{P}$ , 即 $S_a \equiv S_b \pmod{P}$ , 设为 $S$ , 这个 $S$ 就是 Alice 和 Bob 双方共享的密钥.

而如果我们的 $P, g$ 选的足够好, 则可以保证共享密钥 $S$ 被破解是非常困难的.

#### 中间人攻击

Diffie-Hellman 密钥交换协议可以保证私钥不容易被破解, 但它存在一个问题, 通信双方无法确定对面是否是自己预期的人.

假设现在有一个中间人 Hacker, 他可以窃取到 Alice 发给 Bob 的信息和 Bob 发给 Alice 的信息并进行伪造, 我们以这个场景来讲一下这个攻击.

Alice 发给 Bob 公钥, 而在发送过程中被 Hacker 截胡了, Hacker 得到了 Alice 的公钥 $A$ , 他现在自己选择了一个私钥 $x$ , 然后自己生成了一个公钥 $g^x$ 发送给了 Bob, 而 Bob 得到了公钥, 误认为这个是 Alice 的公钥, 然后给 Alice 发送了 $g^{b}$ ， 而这个公钥被 Hacker 截胡, 至此, Hacker 与 Bob 建立了密钥交换协议, 其共享密钥为 $g^{bx}$ , 而 Hacker 转过头又选择了一个私钥 $y$ , 将 $g^y$ 发送给了 Alice, 然后与 Alice 建立了另一个密钥交换协议, 共享密钥为 $g^{ay}$ , 至此, Alice 与 Bob 都分别与 Hacker 建立了密钥交换协议, 而双方都不会想到对面的人是 Hacker, Alice 发送给 Bob 的消息被 Hacker 截胡后, Hacker 可以使用 $g^{ay}$ 来进行解密, 甚至可以再利用 $g^{bx}$ 伪造消息发送给 Bob, 很显然, 这个密钥交换协议已经不安全了, 这就是中间人攻击的过程.

不过要注意的是, Hacker 在此过程中还是无法得知双方的私钥 $a, b$ , 这一点依旧由离散对数问题保证.

### 改进

由于原始的 Diffie-Hellman 无法确认对方的身份, 因此在后来针对这个问题进行了一些新的方法.

#### 数字签名

现在假设 Alice 和 Bob 都有一套公钥 $PK$ 与私钥 $SK$ , Alice 随机选择了私钥 $a$ 得到 $A = g^a \pmod{P}$ , 但这一次他不会直接把 $A$ 发送给 Bob, 而是使用 $SK_A$ 对 $A$ 进行签名 $\sigma_a = Sign(A, SK_A)$ , 然后发送 $\left(A, \sigma_a \right)$ 给 Bob, Bob 在收到消息后可以使用公钥 $PK_A$ 验证这个消息是否由 Alice 发送, 中间人 Hacker 由于无法得知私钥 $SK_A$ , 就无法生成能使用公钥 $PK_A$ 验证通过的签名, 那么也就无法实施中间人攻击了. 这个过程对于 Bob 给 Alice 传递消息也是同理的.

#### 数字证书

这个更多是保证 Alice 和 Bob 手中的公钥 $PK_A, PK_B$ 真的是对方的公钥, 对此双方可以找公证机构进行公证, 得到数字证书, 帮助双方确认公钥是属于对方的.

经历这些改进后, 后续就慢慢演化为了现代的认证密钥交换协议.
